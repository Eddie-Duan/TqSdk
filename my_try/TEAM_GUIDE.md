# 团队作战手册（carry 组合）

> 考核：11.11 – 12.15，5 人 × 100 万 = 500 万，**按组合计排名**。
> 策略：横截面 carry（展期收益）多空组合，每周五收盘前调仓一次。

---

## 一、最重要的一条：只交易近月

指令单里的 `近月合约` 才是要下单的合约。`远月合约` **只用来算信号**，不要对它下单。
如果对两条腿都下单，就变成了另一个策略（跨期价差），成本和保证金都会翻倍。

另外确认：考核平台必须支持**做空**和**保证金交易**，否则这套策略不成立。

---

## 二、每周五的标准流程（14:45–15:00）

| 时间 | 谁 | 做什么 |
|---|---|---|
| 14:45 | 1 人（跑单员） | 在 `TqSdk\` 下运行指令单生成命令，把 `my_try/output/orders_YYYYMMDD.csv` 发到群里 |
| 14:45–14:55 | 5 人各自 | 按 CSV 里自己名下那几行，在考核平台下单；**只下近月，按"手数"下** |
| 14:55–15:00 | 5 人各自 | 回群里报"完成/有差异"，差异写清楚哪个品种 |
| 收盘后 | 跑单员 | 存档 CSV + 记录本周收盘权益 |

命令：

```powershell
cd C:\Users\DUANboyang\Desktop\TqSdk
python my_try\22_runner.py --members 5 --per-account 1000000
```

改仓位规模只改两个参数：`--lev`（杠杆，默认 4）、`--per-account`（每人权益）。

## 二点五、每天收盘后：记一行净值（不能省）

这是整条流程里**唯一事后补不回来**的东西。每过一天就少一天的历史。

```powershell
# 考核平台：抄 5 个账户的权益总和
python my_try/23_report.py --manual 5034567 --note "第1周周四"

# TqKq 排练账户：自动抓
python my_try/23_report.py --snapshot --note "排练"
```

出报告（生成图 `output/report.png` + 文字汇总 `output/report.txt`）：

```powershell
python my_try/23_report.py --report
```

报告内容：区间收益、年化、波动、夏普、最大回撤、按周胜率、逐周明细、净值曲线 + 回撤曲线。
样例见 `output/report_sample.png`（用模拟数据生成的样式示例，不是真实业绩）。

## 三、分工

| 角色 | 职责 |
|---|---|
| 跑单员（1 人） | 每周生成指令单、存档、维护 `runner_log.csv`、记录团队净值 |
| 执行员（5 人，含跑单员） | 各自账户按指令单下单、盘后核对持仓 |
| 复核员（1 人，可由跑单员兼） | 每周核对"指令手数 vs 实际持仓"，发现差异立刻补单 |

## 四、风险规则（写死，不临时改）

1. **团队总权益回撤 -8%** → 下周杠杆减半（`--lev 2`）。
2. **回撤 -12%** → 全部平仓，停止调仓，写复盘。
3. 单个成员账户保证金占用超过 40% → 立刻报跑单员。
4. 不因为"某个品种看着要涨/要跌"临时加仓，信号和仓位分离。

参考：4 倍杠杆下，24 个交易日的历史 5% 分位约 -8%、95% 分位约 +7.4%。
**这就是一个方差受控的赌局，不是稳定盈利系统**——别在亏损周临时改规则。

## 五、每周对账清单

- [ ] 指令单 CSV 已存档（`my_try/output/orders_日期.csv`）
- [ ] 每人持仓与指令手数一致（方向、手数、合约月份）
- [ ] 团队总权益、保证金占用已记录
- [ ] **每天**的权益快照已写入 `output/snapshots.csv`（漏一天就是永久缺一天）
- [ ] 下周调仓前没有遗留未成交委托

漏跑一天怎么办：**不补单**。下周五照常按新信号调整即可，carry 是慢信号，少调一次影响很小；
连续补单反而容易在错误的价格上追。

---

## 六、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 对近月和远月都下单 | 变成跨期套利，保证金翻倍 | 只下近月 |
| 按"名义金额"自己换算手数 | 算错乘数，敞口失真 | 照抄指令单的手数 |
| 用了过期的换月表 | 近月/远月取错，信号全错 | 用 `22_runner.py` 现算，不要手改 |
| 亏损后加杠杆想翻本 | 回撤翻倍 | 按第四节规则执行 |
